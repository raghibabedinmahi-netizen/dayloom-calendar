# DayLoom Calendar — Final

A dark, responsive personal planner built with plain HTML, CSS and JavaScript.

## Sections
- Dashboard
- Calendar — calendar only, with no notes/task panel beside it
- Tasks
- Goals
- Notes
- Focus / Pomodoro
- Reminders
- Profile
- Settings

## Included
- Collapsible sidebar
- Live clock and date
- Dark-only interface
- Monthly calendar
- Jump to any date
- Task creation and completion
- Goals and progress
- Separate full Notes page
- Pomodoro focus timer
- Reminders
- Profile customization
- Demo login UI
- Browser localStorage persistence
- JSON data export
- Responsive layout

## Run
No npm, Vite or build process is required.

Just open `index.html` in your browser, or use VS Code Live Server.

## Important
The login interface is a frontend demo. It does not create real cloud accounts or real Google authentication. For real account login, email confirmation and cross-device cloud saving, connect Firebase, Supabase, or your own backend.
