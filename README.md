# 🌙 DayLoom

> A simple, modern and personal productivity workspace for managing your days, tasks, goals, notes and reminders in one place.

DayLoom is a personal productivity and planning web application designed to help users organize their everyday life in a clean and simple interface.

---

## ✨ Features

### 📅 Calendar
- Monthly calendar view
- Previous / Next month navigation
- Jump to a specific date
- Today button
- View tasks directly from calendar dates
- Easy date-based planning

### ✅ Tasks
- Create new tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks
- Organize daily activities

### 🎯 Goals
- Create personal goals
- Track goal progress
- Update progress
- Delete completed or unwanted goals

### 📝 Notes
- Separate notes workspace
- Create and edit notes
- Save notes automatically
- Useful for personal ideas, plans and information

### ⏱️ Focus
- Pomodoro-style focus timer
- Start / pause / reset timer
- Useful for study and development sessions

### 🔔 Reminders
- Create reminders
- View upcoming reminders
- Delete reminders when no longer needed

### 👤 User Profile
- Personal profile
- Username
- Email
- Bio
- Profile customization

### 🔐 Authentication
- User login
- Sign out

### ⚙️ Settings
- 12 / 24-hour clock preference
- Auto-save settings
- Data export
- Clear personal data
